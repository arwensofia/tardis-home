# TARDIS Home

An Apple TV-style, ad-free launcher for a Samsung UE50TU7005 TV (Tizen 5.5), installed through Developer Mode.

- `outputs/TARDIS-Home/` – the app itself (HTML/CSS/JS + tile art). See its README for how it works.
- `work/install.sh` – build, sign and install to the TV.
- `work/samsung-cert/request_certs.py` – get Samsung author/distributor certificates for the TV.
- `work/tile-art/` – source and renderer for the app tiles.

To set everything up again from scratch, follow **[HANDOFF.md](HANDOFF.md)**.
